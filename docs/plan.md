# 第七站：Back-end 模組 2

## 介紹

本系統為供管理員與出版社使用的書籍管理系統。每本書記錄都有一個獨特的識別碼，稱為**國際標準書號（ISBN）**。

系統包含以下公開頁面：

- 公開 ISBN 批量驗證頁面
- 公開書籍頁面
- 公開出版社頁面

---

## 系統存取

專案計畫可通過以下 URL 訪問：

```
https://webXX.web.tw/XX_module_d/
```

其中 `XX` 為崗位號碼。

### 管理員登入

- 登入頁面路徑：`/XX_module_d/login`
- 超級管理員帳號：`admin`，密碼：`1234`
- 出版社管理員可使用各自的帳號登入
- 未登入時嘗試存取書籍編輯與管理功能將回傳 **401 錯誤**

## ISBN 格式說明

每本書的 ISBN 為唯一值，由 **13 位數字**組成，分為 5 個部分，以連字號（`-`）分隔：

| 部分 | 說明 |
|------|------|
| 第一組 | `978` 或 `979` |
| 第二組 | 國家、語言或區位代碼 |
| 第三組 | 出版社代碼 |
| 第四組 | 書序碼 |
| 第五組 | 校驗碼 |

### 校驗碼計算方式

1. 取前 12 位數字，例如：`978-986-181-728`
2. 計算加權和（奇數位 ×1，偶數位 ×3）：

   ```
   9×1 + 7×3 + 8×1 + 9×3 + 8×1 + 6×3 + 1×1 + 8×3 + 1×1 + 7×3 + 2×1 + 8×3 = 164
   ```

3. 校驗碼 = 加權和除以 10 的**負餘數**：`164 = 17×10 - 6`
4. 本例校驗碼為 `6`，完整 ISBN 為 `978-986-181-728-6`

## 書籍管理

### 書籍列表

- 超級管理員可看到**所有書籍**的列表
- 出版社管理員只能看到**所屬出版社**的書籍
- 支援關鍵字搜尋
- 可點擊書籍進入管理頁面，或透過以下路徑訪問：

  ```
  /XX_module_d/books/[ISBN]
  ```

  例如：`/XX_module_d/books/978-986-181-728`

- 出版社管理員嘗試存取其他出版社書籍時，回傳 **403 錯誤**
- 書籍頁面列出所有書籍資訊與圖片；未上傳圖片時顯示預設圖片

### 新增書籍

訪問路徑：`/XX_module_d/books/new`

#### 書籍資料欄位（皆為必填）

| 欄位 | 說明 |
|------|------|
| 書籍名稱 | |
| 描述 | 可多行文字 |
| 作者 | |
| ISBN | 僅需輸入前 12 位，系統自動計算校驗碼 |

- 每本書籍必須屬於一間出版社
- ISBN 中的出版社代碼需與所選出版社相同
- ISBN 格式錯誤或校驗碼錯誤時需顯示錯誤訊息
- 出版社管理員只能新增所屬出版社的書籍

### 書籍圖片上傳

- 每本書籍可上傳多張圖片
- 第一張圖片作為封面顯示
- 可上傳、更換或移除圖片

### 編輯書籍

- 超級管理員與出版社管理員均可修改書籍資料與圖片
- 修改時需顯示原先的書籍資料與圖片供使用者編輯

### 隱藏與刪除書籍

- 可將書籍標記為**隱藏**或重新顯示
- 可永久刪除已隱藏的書籍
- 隱藏的書籍不顯示在公開頁面與 JSON API 中

## JSON API

### 書籍列表

```
GET /XX_module_d/books.json
GET /XX_module_d/books.json?query=KEYWORD
```

- 支援關鍵字查詢（書名或描述中包含關鍵字）
- 分頁功能，每頁 **3 筆**
- 僅回傳**顯示狀態**且**出版社已啟用**的書籍
- 輸出的 ISBN 必須為完整格式並包含連字號（`-`）

### 單一書籍

```
GET /XX_module_d/books/[ISBN].json
```

- ISBN 中的連字號可省略
- 書籍不存在或已隱藏時回傳 **404**

## 公開頁面

### 公開 ISBN 批量驗證頁面

- 任何使用者均可輸入多個 ISBN 進行批量驗證
- 輸入的 ISBN 可省略連字號
- 符合以下條件的 ISBN 視為**有效**：存在於資料庫中、未被隱藏、出版社未被停用
- 使用文字輸入區，以換行符號分隔多個 ISBN
- 若所有 ISBN 均有效，頁面頂部顯示「All valid」提示文字與綠色勾勾

### 公開書籍頁面

訪問路徑：`/XX_module_d/01/[ISBN]`（`01` 為固定數字，ISBN 連字號可省略）

#### 範例

| URL | 結果 |
|-----|------|
| `/XX_module_d/01/978-986-181-728-6` | 正常訪問 |
| `/XX_module_d/01/978986181728-6` | 正常訪問 |
| `/XX_module_d/01/978-9-8-6-1817286` | 404 錯誤 |

- 書籍不存在、已隱藏或出版社已停用時顯示 **404 錯誤頁面**
- 頁面採用**行動裝置友善排版**

#### 必須顯示的欄位

- 書籍名稱
- 書籍描述
- 所有圖片
- 作者
- ISBN
- 出版社名稱（可點擊連結至出版社公開頁面）

### 公開出版社頁面

- 透過點擊書籍公開頁面中的出版社名稱連結進入
- 顯示出版社所有資訊
- 列出該出版社所有**狀態為顯示**的書籍
- 頁面採用**行動裝置友善排版**

#### 書籍列表必須顯示的欄位

- 書籍名稱
- 書籍描述
- 書籍封面
- 作者
- ISBN

## 選手指引

### 資料庫建置

- 將出版社與書籍資料存於資料庫
- 密碼**不得明碼儲存**
- 請匯出資料庫結構，包含**外鍵約束（FK constraints）**與正確欄位型別
- 請提供 ER 圖，儲存為 `er-model.png`
- 請考量資料庫正規化
- **ISBN 欄位應設為索引**
- 請將提供的樣本資料輸入資料庫以便評分

### 其他注意事項

- 可將專案放於子資料夾或使用不同通訊埠，請確保從 `https://webXX.web.tw/XX_module_d/` 可正確重定向
- 文件中提到的路徑可能與子資料夾相關，例如登入頁面實際路徑可能為：
  - `/XX_module_d/public/login`
  - `/XX_module_d/index.php/login`
  - `http://webXX.web.tw:3000/XX_module_d/login`
- 請提供 `expert_readme.txt`，包含執行指南（即使使用預設路徑也必須提供）
- 使用 Node.js 時，請注意 Windows（工作站）與 Linux（伺服器）的 `node_modules` 可能不同，請避免使用錯誤的 `node_modules`
- 本專案將使用 **Chrome 瀏覽器**進行評估
