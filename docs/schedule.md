# 一個月密集教學排程（假設 兩次/週授課）

## 建議框架與工具
- 框架：Laravel 10（優先，因為教學資源完整且開發效率高）。
- 資料庫：MySQL -> 授課者準備。
- 測試：PHPUnit -> 授課者準備。
- 給他們辦Github帳號，讓他們`git push -u origin master`沒關係。
- 或許讓你去教他們之前可以讓他們自己用AI去產生這份試題，看他們使用AI的能力到哪裡(?)。
- 想法：每段實作都要有「你先示範 1 次，學生做 1 次」，在上課的一個小節至少 1 次「口頭解題」：要求學生用自己的話解釋資料流。

## 4 週課程大綱

### 第 1 週：基礎打底（Laravel + REST 基本功）
- 主題：
  - Laravel 專案結構、路由、Controller、Migration、Model
  - REST API 基本設計（HTTP 方法、狀態碼、JSON 格式）
  - Request Validation（必填、格式、唯一值）
  - 資料正規化
- 任務：
  - 完成 publishers CRUD API
  - 完成 books CRUD API（先不含圖片）
- 小考 1（60 分鐘）可以open book：
  - 新增 Publisher + 驗證唯一欄位
  - 查詢列表（含分頁）
  - 錯誤格式一致化

### 第 2 週：登入授權與角色權限
- 主題：
  - 密碼雜湊、登入流程、Session 或 Token
  - 角色與授權（超級管理員 / 出版社管理員）
  - 401、403、404 的實作時機
- 任務：
  - 完成登入 API
  - 完成角色中介層（middleware）
  - 限制出版社管理員只能操作自己出版社資料
- 小考 2（60 分鐘）：
  - 包括先前的小考
  - 完成一個受保護 API
  - 驗證不同角色的可見範圍
  - 錯誤碼正確回傳

### 第 3 週：規格題核心（ISBN、公開 API、檔案上傳）
- 主題：
  - ISBN 格式驗證與校驗碼計算
  - 公開 API 規格輸出（資料結構固定）
  - 圖片上傳、封面邏輯、預設圖
- 任務：
  - books.json 與 book detail json 完成
  - 支援 query、分頁（每頁 3 筆）
  - 隱藏書籍、停用出版社後 API 不可見
- 小考 3（75 分鐘）：
  - 包括先前的小考
  - 給定需求文件，限時完成 2 個 API 端點
  - 驗證 ISBN（可含或不含連字號）

### 第 4 週：整合、壓力測試、模擬賽
- 主題：
  - 全流程串接與資料一致性檢查
  - 邊界案例（不存在、已隱藏、停用出版社）
  - 快速除錯與時間管理
- 任務：
  - 完整跑一次規格功能清單
  - 製作 expert_readme.txt（部署與操作說明）
  - 匯出資料庫結構與 ER 圖（er-model.png）
- 小考 4（60 分鐘）：
  - 限時修 Bug + 補齊缺漏 API
- 期末模擬考（120 分鐘）：
  - 包括先前的小考
  - 給一份縮小版題目，要求獨立完成
  - 依評分表打分並複盤

## 每週交付物（必交）
- 1 份 Git 提交紀錄（至少 5 次 commit，訊息清楚）
- 1 份 API 清單（路徑、方法、範例請求/回應）
- 1 份錯誤清單（本週錯誤、原因、修正方式）
- 1 份下週計畫（具體到端點或功能），在這週上課前就先準備好
